## About Volcano PC

Volcano PC is a Windows-focused Roblox script executor that injects Lua scripts into active Roblox game sessions. It can be used for custom gameplay changes, automation workflows, and scripting experiments. The interface is centered around quick access: injection takes one click and does not require a complicated attachment workflow or extensive setup.

The application also provides a categorized script hub with more than 500 community-verified entries. Its collection covers GUI utilities, game-specific modifications, and grinding automation, while built-in search makes scripts easier to find. A persistent execution queue lets users arrange several scripts and run them consecutively without starting each one manually.

## Frequently Asked Questions

**Is Volcano PC safe to use?**  
Volcano PC is supplied as-is for educational and experimental use. You are responsible for deciding whether to use it. The developers do not guarantee that it will avoid detection or prevent account actions.

**Does it support the newest Roblox version?**  
Its automatic update system is intended to preserve compatibility with recent Roblox builds. A Roblox update can still interrupt injection temporarily until a corresponding patch becomes available.

**What distinguishes Volcano PC from other executors?**  
The project emphasizes a lightweight experience without keys, premium levels, or key systems, while also including an integrated script hub. It is available for use immediately after downloading.

**Could using Volcano PC result in a ban?**  
Third-party executors are against the Roblox Terms of Service, so account bans may occur. Roblox account actions are not the responsibility of the developers.

**Where does Volcano PC save scripts?**  
Scripts imported by the user are located in `scripts/user/`. Cached script hub content is kept under `scripts/hub/`. Either directory can be backed up or moved manually.
